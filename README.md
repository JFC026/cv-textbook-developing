## 二、总目录

### 1. 第一章 [K-近邻 (K-NN)](./01-knn/README.md)
-   **内容**：从零实现最简单的无监督分类算法，深入理解图像数字化（采样与量化）过程。
    
-   **重点**：距离度量、K值选择、交叉验证、矩阵运算优化、特征预处理与归一化。
    
-   **实验**：在 MNIST 数据集上达到 97.22% 的测试准确率，并通过可视化分析各类别性能与错误模式。


### 2. 第二章 [Softmax 分类器](./02-softmax/README.md)
-   **内容**：实现多类别线性分类模型，掌握从线性映射到概率输出的完整流程。
    
-   **重点**：Softmax 函数、交叉熵损失、梯度推导、反向传播、L2正则化、批量训练。
    
-   **实验**：在 Fashion-MNIST 上达到 84.10% 验证准确率，在鸢尾花数据集上达到 96.67% 验证准确率，验证线性模型在不同数据特性下的表现差异。



### 3. 第三章 [两层全连接神经网络](./03-two-layer-nn/README.md)
-   **内容**：构建具有隐藏层的简单神经网络，引入非线性激活函数，实现前向与反向传播。
    
-   **重点**：感知机与神经元原理、ReLU 激活、参数初始化（He/Xavier）、梯度裁剪、Adam优化器。
    
-   **实验**：在 MNIST 上达到 87.54% 测试准确率，在 CIFAR-10 上出现严重过拟合（训练集 75.54% vs 测试集 53.05%），揭示全连接网络处理图像数据的局限性。


### 4. 第四章 [卷积神经网络 (CNN)](./04-cnn/README.md)
- **内容**：从全连接网络引入CNN，阐述其核心机制（局部连接、权值共享、池化），详细解析卷积层、池化层、全连接层的工作原理与数学计算，并提供了针对MNIST与CIFAR-10数据集的完整CNN实现。

- **重点**：CNN三大核心机制（局部连接、权值共享、池化）、卷积与池化的前向/反向传播实现、多通道与多卷积核处理、BatchNorm、Dropout、Adam优化器与L2正则化在CNN中的集成应用。

- **实验**：在MNIST上使用10000训练样本达到 97.90% 测试准确率，训练稳定且过拟合控制良好；在CIFAR-10上采用4核心并行训练，最终测试准确率 65.99% ，存在一定过拟合，模型对相似类别（如猫/狗）易混淆。

### 5. 第五章 [循环神经网络 (RNN)](./05-rnn/README.md)
- **内容**：从序列处理需求出发引入RNN，回顾其历史奠基（Elman的SRN架构），详细阐述RNN的时序记忆原理、内部结构与数学形式（前向传播、BPTT），并基于字符级语言建模任务实现了SimpleRNN与ImprovedRNN的完整代码。

- **重点**：RNN的时序记忆机制、随时间反向传播（BPTT）与梯度消失/爆炸问题、字符级文本生成的完整流程。

- **实验**：在Tiny Shakespeare数据集上进行字符级文本生成训练与评估，基础SimpleRNN取得测试困惑度6.66、生成文本具有基本语法与角色格式；改进版（Xavier初始化、Dropout、学习率调度）训练不稳定、早停过早，测试困惑度14.15、生成质量下降，表明简单任务中复杂改进未必有效，需针对性调优。

## 三、快速开始参考

### 环境配置
```bash
# 1. 克隆项目
git clone https://github.com/JFC026/cv-textbook-developing.git

# 2. 进入项目目录
cd cv-handcraft-python

# 3. 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 或 venv\Scripts\activate  # Windows

# 4. 安装依赖
pip install -r requirements.txt

# 5. 运行示例代码（以KNN为例）
cd 01-knn
python main.py
```
